- **Study design:** [RCT / phase 1-2-3 / retrospective / in vitro / animal / registry / other]
- **Sample size:** N=

## Quick-reference: hedge requirements by evidence tier

| Evidence tier | Required hedge | Example |
|---|---|---|
| Phase 1 / pilot / n<50 | "in a preliminary study of [N] participants" | In a preliminary study of 22 participants… |
| Phase 2 / n 50–200 | "in a phase 2 study" or "early clinical data suggests" | Phase 2 data suggests… |
| Phase 3 / pivotal | "in a phase 3 trial" — may omit "may" for primary endpoint | Phase 3 results showed… |
| Meta-analysis | "a meta-analysis of [N] studies found" | A meta-analysis of 7 studies found… |
| In vitro / animal | "in preclinical studies" — must not imply human applicability | Preclinical models demonstrated… |
| Regulatory clearance | State exactly what was cleared and for what indication | FDA-cleared for [specific indication] in [population] |

All tiers: never use "proven," "guarantees," or "cures" regardless of evidence strength.
