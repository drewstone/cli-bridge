# Helix Bio — Style Guide

**Channel:** LinkedIn
**Voice:** Cautious, claim-substantiated — see `voice.md` for full register
**Format constraints:** LinkedIn single-image ad, carousel, and sponsored content

---

## Copy length

| Element | Character limit | Target |
|---|---|---|
| Headline | 150 chars max | 70–90 chars (leave room for legal qualifications) |
| Intro text | 600 chars max | 300–400 chars (LinkedIn truncates at ~150 chars before "See more") |
| Description | 100 chars | 60–80 chars |
| CTA | Platform-provided options | "Learn More" or "Download" — not "Get Started" (too sales-forward) |

**Leave 15–20% copy slack for legal qualifications.** Legal will add hedge language. If you write to the character limit, legal modifications will break the format.

---

## Typography (when designing assets in Figma)

Pull from `[helix-bio]` design token library in Figma.

- **Headlines:** Clean sans-serif; no display or decorative fonts
- **Body:** Same family, regular weight
- **No all-caps headline** — reads as a direct claim; legal prefers sentence case
- **Data callouts:** If citing a number from a study, present it in the same weight as surrounding text; do not enlarge or bolden it (bolded stats imply stronger certainty than hedged language conveys)

---

## Visual direction

- **Palette:** Blues, grays, white. Biotech credibility palette. No warm tones that read as wellness/consumer.
- **Imagery:** Lab context, data visualization, molecular imagery, researcher-at-work. No stock "happy patient" imagery — this is not DTC.
- **Charts/graphs:** If using study data visually, label axes, include sample size in the caption, and mark as "representative data" unless the visual is from the actual study and approved for use.
- **Logo lockup:** Bottom-right, consistent size across variants.
- **No testimonials** in visual assets unless explicitly substantiated and legal-cleared (FTC endorsement rules apply).

## LinkedIn ad structure

### Single-image ad
```
[Visual: lab/data/research imagery]
[Intro text: peer-professional hook — 1–2 sentences, claim annotated]
[Headline: evidence-led value prop]
[Description: hedge + call to evidence]
[CTA: Learn More / Download]
```

### Carousel
- Card 1: Hook (tension or question)
- Cards 2–4: Evidence (study findings, one per card, CLAIM-ID annotated)
- Card 5: CTA + qualifier

### Sponsored content (long-form)
- Opens with a research question, not a product statement
- Cites peer-reviewed sources inline
- Product mention deferred until claim is established

---

## What this brand never looks like

- Consumer supplement aesthetic (gradients, lifestyle photography, transformation before/after)
- Startup hype (bold claims, exclamation points, "disrupting" language)
- Academic paper (not dry to the point of disengagement — still written for a decision-maker)
- Any visual or copy element from SunwellCo, Atlas Survey, ForgeFit, or any other roster client
