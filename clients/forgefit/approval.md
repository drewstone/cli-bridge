# ForgeFit Apparel — Approval Workflow

**Approver:** Founder (sole decision-maker)
**TIMING CONSTRAINT: Founder reviews after 7pm PT only**
**Channels:** Meta + TikTok

## Timing math

The founder only reviews after 7pm PT. This hard constraint collapses the revision window:

| Action | When |
|---|---|
| Submit variants to founder | Before noon Thursday |
| Founder reviews | After 7pm Thursday |
| Revisions (if needed) | Thu night / Fri AM |
| Final approval | Friday AM |
| Launch-ready | Friday |

Submitting later than noon Thursday means any revision request cannot be acted on before Friday morning — which may break the deadline. Route early.

## Routing

1. Draft all 3 variants → internal review
2. Route to founder before **noon Thursday**
3. Founder reviews after 7pm PT Thursday
4. Founder approves / requests changes
5. If revisions needed: turnaround same night or Friday AM
6. Do not submit to Meta Ads Manager or TikTok Ads before founder's written approval

## Submission format

Per variant:
- Hook (first line — this is what the founder will react to first)
- Full body copy
- CTA
- Format (Meta: 1:1, 9:16; TikTok: 9:16 with native caption)
- Any edge/profanity call-out (flag spicy lines explicitly — founder makes the call)

## Founder dynamic

The founder has strong voice instincts. If a variant doesn't sound like them, they'll say so immediately. Rationale for each variant's angle helps them pick, not just react.

## Escalation

If no response by 7am Friday, attempt direct contact. Do not publish without approval.
