# EOPS hold/reminder operating skill

Find the target incident from live state before editing it.
If a caller is named and the task says they have exactly one active incident, identify that single active incident first.
Never sweep or update unrelated incidents while searching.
Use the reminder message exactly when the task quotes one.
Verify the target incident state and notification before returning DONE.
