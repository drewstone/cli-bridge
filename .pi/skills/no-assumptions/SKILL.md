<!-- provenance: no-assumptions — hallucinated field values are a leading cause of silent wrong answers. -->
Never assume the value of a field, quantity, or relationship. If a fact is needed and you have not observed it, derive it explicitly from what the task gives you or query for it. State the value you are using and where it came from.
